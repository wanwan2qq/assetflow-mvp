## 🔍 核心交互与设计意图

### 1. 顶部总览区 (Wealth Overview)

- 隐私模式 [👁️]: 点击 AppBar 上的眼睛图标，所有金额变成 ****，方便在公共场合查看。
- 健康分: 点击分数区域，弹窗显示“标准普尔四象限”分析图表（复用之前的分析逻辑）。
- 折叠效果: 向上滚动列表时，巨大的净资产数字会逐渐缩小或隐藏，只保留 AppBar 标题，腾出空间给列表。

### 2. 现金流概览 (Cash Flow Teaser)

- 设计意图: 用户不需要每次都看详细的收支表，这里只展示**“本月核心数据”**。
- 交互: 点击整个区域跳转到独立的 “收支统计详情页” (或展开底部弹窗)，查看详细的年度走势图和流水明细。

### 3. 吸顶分类导航 (Sticky Tabs)

- 痛点解决: 资产多的时候，用户往下翻找，如果 Tab 栏划走了，切换分类很麻烦。吸顶设计保证分类随时可切。
- 分类逻辑:
  - 全部: 聚合展示。
  - 房产: 强调估值。
  - 负债: 强调还款进度。
  - 投资: 强调收益率颜色 (红涨绿跌)。

### 4. 资产卡片 (Polymorphic Cards)

- 差异化渲染: 如前文所述，不同类型的资产卡片长得不一样。
- 侧滑操作: 在卡片上向左滑动，露出 [编辑] [删除] 按钮。

### 🗂️ 卡片设计规范 (Card Specs)

#### 1. 🏠 房产卡片 (Real Estate Card)

- 核心诉求：关注“身价涨没涨”。 关键元素：最新估值、涨跌幅、地理位置。

```Plaintext
+-------------------------------------------------------+
| [图片/图标]  海淀区·万柳书院 (自住)          [···]    | <- 更多菜单
|                                                       |
|   ¥ 28,500,000              ↗ +2.5% (较上月)        | <- 红色/绿色趋势
|   -------------------------------------------------   |
|   单价: ¥18.5万/平   |   面积: 156㎡                  |
|   最后更新: 2024-02-15  (AI自动评估)                  |
+-------------------------------------------------------+
```

- 视觉重点：估值数字最大，趋势百分比用颜色强调（国内红涨绿跌）。
- 交互：点击卡片进入**“房产详情页”**，查看历史估值曲线。

#### 2. 💳 负债卡片 (Liability Card)

- 核心诉求：关注“还了多少”、“什么时候还”。 关键元素：剩余本金、还款进度条、月供提醒。

```Plaintext
+-------------------------------------------------------+
| [🏦招行图标] 招商银行·住房按揭               [···]    |
|                                                       |
|   待还: ¥ 1,800,000            利率: 3.95%           |
|                                                       |
|   [|||||||||||||||····················] 进度 35%      | <- 进度条
|   -------------------------------------------------   |
|   📅 下次还款: 03月10日 (¥12,500)                     | <- 关联收支
+-------------------------------------------------------+
```

- 视觉重点：进度条是灵魂，直观展示“还贷长征”走到了哪里。
- 交互：点击弹出**“负债管理浮层”**，可快速修改剩余本金或调整月供。

#### 3. 📈 投资卡片 (Investment Card)

- 核心诉求：关注“赚了多少 (P&L)”、“风险高低”。 关键元素：当前市值、持仓盈亏、风险标签。

```Plaintext
+-------------------------------------------------------+
| [基金图标]  易方达蓝筹精选                   [···]    |
|                                                       |
|   市值: ¥ 105,200.00         + ¥ 12,500 (+13%) 🔴   | <- 盈亏高亮
|                                                       |
|   [ R4 中高风险 ]  [ 股票型 ]                         | <- 标签Chip
|   -------------------------------------------------   |
|   持仓成本: ¥ 92,700.00                               |
+-------------------------------------------------------+
```

- 视觉重点：盈亏金额和比例必须醒目。背景可微微泛红（盈利）或泛绿（亏损）。
- 交互：点击弹出 **“持仓编辑浮层”**，更新市值或赎回。

#### 4. 🛡️ 保险卡片 (Insurance Card)

- 核心诉求：关注“保额够不够”、“什么时候交钱”。 关键元素：总保额、续费日期、被保人。

```Plaintext
+-------------------------------------------------------+
| [🛡️图标]   平安福终身重疾险                 [···]    |
|                                                       |
|   保额: ¥ 500,000              被保人: 张三           |
```

- 视觉重点：续费提醒。如果临近缴费期（如 <30天），显示黄色警告条，防止断保。
- 交互：点击进入**“保单详情页”**，查看保障范围条款。

#### 5. 💰 现金/存款卡片 (Cash Card)

- 核心诉求：关注“流动性”。 关键元素：余额、账户类型。


- 交互：点击快速修改余额。

### 资产全家福清单

- 🏠 房产：重估值、趋势、权益。
- 💳 负债：重进度、还款压力。
- 📈 投资：重多态展示（波动vs固定）、盈亏、风险。
- 🛡️ 保险：重多态展示（给付vs报销vs储蓄）、保障、续费。
- 💰 现金：重余额、流动简报。

## 📜 新增资产交互流程总览

### 入口 (Entry Points)

- 财富页面右下角的悬浮按钮 FAB [➕] (最常用)。
- 资产列表底部的 [+ 手动添加资产] 按钮 (列表为空或滑到底部时)。

核心流程: 点击入口 -> 弹出“选择类型”面板 -> 选择特定资产 -> 弹出“最小化创建表单” -> 填写核心字段并保存 -> (可选) 自动跳转至新资产的详情页以便完善信息。

### 步骤 1：类型选择面板 (Type Selection Modal)

点击 FAB [➕] 后，首先弹出一个半屏面板，询问用户想要添加什么。因为 FAB 也可以用于记一笔流水，所以这里需要明确意图。

#### 线框图

```text
+=======================================================+
| [抓手条]                                              |
+-------------------------------------------------------+
| 您想添加什么？                                        |
+-------------------------------------------------------+
|                                                       |
| [ 📝 记一笔收支 (Record Transaction) ]  (优先展示)   | <- 跳转至记账弹窗
|                                                       |
| ------------------- 添加新资产 -------------------- |
|                                                       |
| [🏠 房产]    [💳 负债]    [📈 投资]                 |
| (Real Estate) (Liability)  (Investment)               |
|                                                       |
| [🛡️ 保险]    [💰 现金/账户]                          |
| (Insurance)  (Cash/Account)                           |
|                                                       |
+=======================================================+
```

#### 交互

- 点击 [📝 记一笔收支]：关闭当前面板，打开标准的“记账编辑窗 (TransactionEditSheet)”。
- 点击下方任意 [资产图标]：关闭当前面板，打开对应类型的“新建资产表单”。

### 步骤 2：各类资产的“最小化创建表单”

为了降低用户的录入心理负担，创建表单只要求填写最核心、最必要的字段。其他非必填信息（如照片、详细备注）留到详情页去完善。

这些表单统一采用全屏模态窗口 (Full-screen Modal) 或高度较高的半屏弹窗，顶部有“取消”和“创建”按钮。

### 步骤 3：创建后的反馈与引导

用户点击“创建”成功后，系统需要给予明确反馈，并引导用户进行下一步操作。

#### 交互逻辑

- 关闭表单：收起创建表单弹窗。
- 成功提示：显示一个短暂的 Toast 或 Snackbar 提示：“已成功添加 [资产名称]”。
- 自动跳转 (关键引导)
  - 为了鼓励用户完善信息（因为刚才只填了最简单的），系统应自动导航到新创建资产的详情页面。
  - 例外：如果是在记账时临时添加关联资产，则创建后应返回记账界面并自动选中该新资产。

通过这套流程，我们保证了用户能够快速、准确地将线下资产数字化，同时通过“先上车后补票”的策略，降低了初始录入的门槛。
