# 👤 我的页面 (Profile Page)

在财富管理应用中，“我的”页面不仅是设置中心，更是数据安全和个人隐私的管理枢纽。考虑到我们强调隐私和本地化，这里的核心功能应该围绕数据主权（备份、导出）和安全保护展开。

## 🔍 核心交互与逻辑

- 分组列表结构：采用 iOS 设置风格的分组列表（Grouped List Views），视觉清晰，操作符合直觉。
- 数据主权 (Data Sovereignty)：
  - 备份与恢复：对于本地化应用至关重要。点击进入一个二级页面，管理本地快照或云端同步状态。
  - 导出数据：允许用户将所有资产和流水导出为 Excel/CSV，增加信任感，方便用户迁移或做更复杂的分析。
- 安全锁定：一个简单的开关，开启后，每次冷启动应用需要 FaceID/TouchID 验证，保护隐私。
- 危险区域：将“清空数据”单独放置在底部，使用醒目的红色按钮，点击后必须弹出带有红色警告的二次确认弹窗，防止误操作。
