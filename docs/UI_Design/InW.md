# inW（AI 对话）页面线框图

设计目标：营造一个专业、智能、沉浸式的对话环境，同时方便用户查看上下文信息（如 Fact Sheet）。

## 🔍 元素交互详解

### 导航栏 (AppBar)

- 标题 (inW): 简洁的应用名或 Logo。
- 档案图标 [🗂️] (Fact Sheet Entry):
  - 交互：点击后，从右侧滑出一个抽屉 (Drawer) 或模态窗口。
  - 内容：展示当前的 "Fact Sheet"（AI 记住的用户画像、已录入资产列表）。方便用户随时核对 AI 的记忆是否准确。

### 对话历史区域 (Chat History)

- 消息气泡: 区分 AI（左侧，品牌色背景/边框）和用户（右侧，气泡色）。
- 富文本与组件插槽:
  - AI 的回复支持 Markdown（加粗、列表）。
  - 关键交互点（如录入资产成功、触发行动建议）会插入交互卡片 (Widget)，而不是纯文本。例如上面的 ASSET_CARD。

### 快捷建议栏 (Suggestion Chips)

- 设计: 在输入框上方的一排小胶囊按钮。
- 内容: AI 根据当前上下文生成的快捷回复（如“评估风险”、“下一步做什么”）。
- 交互: 点击即发送该文本，减少用户打字。

### 底部输入栏 (Input Bar)

- 功能按钮: 左侧放“更多/拍照”[➕]，右侧放“语音/发送”[⬆️]。
- 输入框: 支持多行文本输入。

### 底部主导航 (Bottom Navigation)

- 导航栏: [**inW**]  [财富]  [我的]。
- 交互: 点击后，从右侧滑出一个抽屉 (Drawer) 或模态窗口。
