# 用户输入指南 - 如何触发推荐卡片显示

## 📋 概述

本指南详细说明用户需要输入什么信息才能在聊天页面看到新的 `ASSET_CARD` 和 `PRODUCT_CARD` 推荐卡片。

## 🎯 触发机制

### 核心逻辑
卡片显示基于以下条件：
1. **信息完整度** >= 80% → 进入 `analysis` 阶段
2. **资产数量** >= 2个 → 触发投资组合分析
3. **风险识别** → 生成商业产品推荐
4. **新资产添加** → 显示资产卡片

## 📝 用户输入步骤

### 第一步：基本信息收集

用户需要提供**个人基本信息**：

```
示例输入：
"我今年35岁，已婚有孩子，月支出大概2万元，风险偏好比较稳健"
```

**系统识别的关键信息**：
- 年龄段：30-40
- 家庭结构：married_with_kids  
- 月支出：20000元
- 风险偏好：moderate

### 第二步：房产信息

用户需要提供**房产详细信息**：

```
示例输入：
"我在北京朝阳区有一套120平的房子，大概值500万"
```

**系统识别的关键信息**：
- 资产类型：real_estate
- 位置：北京朝阳区
- 面积：120平米
- 价值：5,000,000元

### 第三步：其他资产信息

用户需要提供**至少1-2个其他资产**：

```
示例输入：
"银行里有50万现金，还买了100万的股票基金"
```

**系统识别的关键信息**：
- 现金：500,000元
- 投资：1,000,000元（股票基金，高风险）

### 第四步：触发分析

当信息完整度达到80%时，用户可以**请求分析**：

```
示例输入：
"帮我分析一下我的资产配置"
"我的投资组合有什么问题吗？"
"给我一些理财建议"
```

## 🎨 卡片显示场景

### 场景1：ASSET_CARD - 新资产添加

**触发条件**：用户添加新资产时

**用户输入示例**：
```
"我刚买了一份保险，年缴费1万元"
"新开了个定期存款账户，存了30万"
```

**显示效果**：
- 资产名称：新增保险 / 定期存款
- 资产价值：¥10.0万 / ¥30.0万
- 资产类型：insurance / cash
- 风险等级：低风险
- 相关标签：life_insurance, protection / savings, fixed_deposit

### 场景2：PRODUCT_CARD - 商业产品推荐

**触发条件**：系统检测到风险并匹配到商业产品

**常见风险类型和触发输入**：

#### A. 流动性风险 → 货币基金推荐
```
用户输入：
"我的现金不多，只有10万"
"应急资金不够怎么办？"

系统检测：现金占比 < 10% 或 < 3个月支出
推荐产品：余额宝、货币基金
```

#### B. 房产集中风险 → 投资产品推荐
```
用户输入：
"我的资产主要是房子，占了80%"
"房产比例是不是太高了？"

系统检测：房产占比 > 75%
推荐产品：股票基金、债券基金
```

#### C. 保险缺口 → 保险产品推荐
```
用户输入：
"我没有买过保险"
"家里的保障不够"

系统检测：保险资产为0或过低
推荐产品：人寿保险、重疾险
```

#### D. 投资不足 → 理财产品推荐
```
用户输入：
"钱都在银行存着，没有投资"
"想要更高的收益"

系统检测：投资占比过低
推荐产品：基金定投、理财产品
```

### 场景3：PORTFOLIO_CHART - 投资组合图表

**触发条件**：有2个以上资产且进入分析阶段

**用户输入示例**：
```
"分析我的资产配置"
"我的投资组合怎么样？"
"帮我看看资产分布"
```

**显示效果**：
- 饼图显示各类资产占比
- 房产：76.9%（蓝色）
- 投资：15.4%（橙色）  
- 现金：7.7%（绿色）

## ⚡ 快速触发方法

### 最快看到卡片的输入组合

**一次性输入所有信息**：
```
"我35岁已婚有孩子，月支出2万。在北京有套500万的房子，银行50万现金，买了100万股票基金。帮我分析一下资产配置有什么问题。"
```

**分步骤快速输入**：
```
1. "我35岁已婚，月支出2万，风险偏好稳健"
2. "北京有套房500万，现金50万，股票100万"  
3. "分析我的投资组合"
```

## 🎯 关键触发词

### 进入分析阶段的关键词
- "分析"、"建议"、"配置"
- "投资组合"、"资产分布"
- "理财规划"、"风险评估"
- "有什么问题"、"怎么优化"

### 触发产品推荐的关键词
- "现金不够"、"流动性"
- "房产太多"、"分散投资"
- "没有保险"、"保障不足"
- "收益太低"、"想投资"

### 触发资产卡片的关键词
- "新买了"、"刚开户"
- "增加了"、"又投资了"
- "买了保险"、"存了钱"

## 📊 信息完整度要求

### 必需信息（80%完整度）
- ✅ 年龄段
- ✅ 家庭结构  
- ✅ 月支出或收入
- ✅ 至少2个资产（含房产）
- ✅ 风险偏好

### 可选信息（提升体验）
- 职业信息
- 具体投资品种
- 保险详情
- 负债情况
- 理财目标

## 🔧 故障排除

### 问题1：输入了信息但没有卡片

**可能原因**：
- 信息完整度不足（< 80%）
- 资产数量太少（< 2个）
- 没有触发分析阶段

**解决方案**：
```
补充输入：
"请帮我分析一下我的资产配置"
"我的投资组合有什么建议吗？"
```

### 问题2：只看到文字没有卡片

**可能原因**：
- 前端组件未正确部署
- 数据解析失败

**解决方案**：
- 检查浏览器控制台错误
- 确认前端组件已更新

### 问题3：卡片信息不准确

**可能原因**：
- 信息提取不准确
- 用户输入模糊

**解决方案**：
```
提供更具体的信息：
"我在北京朝阳区有一套120平米的房子，市值500万元"
而不是：
"有套房子"
```
