## 页面整体结构 (SliverScrollView)

页面顶部是一个可折叠的财富总览，向下滚动时顶部折叠，展示资产/负债和收支明细。

|                     财富 (Wealth)                     | <- AppBar (可滚动隐藏标题)

### 交互逻辑说明

#### 财富总览区域 (Wealth Overview)

展示：核心指标（净资产、年度净增、健康分）和趋势图。

##### 交互

下滑：显示完整的总览信息和背景趋势图。
上滑：信息折叠，只保留“净资产”数字在顶部 AppBar，节省空间。
点击“健康分”：弹窗展示四象限分析报告（复用原 Dashboard 的功能）。

#### 资产/负债区域 (Assets & Liabilities)

展示：分类Tab和对应的资产卡片列表。

##### 交互

吸顶 TabBar：当页面向上滚动时，Tab栏会吸附在屏幕顶部，方便用户随时切换分类，不会被划走。
切换 Tab：点击不同Tab（如“房产”、“负债”），下方列表动态刷新为对应类型的资产卡片。
卡片点击：点击具体的资产卡片（如某套房产），进入该资产的详情页（可查看估值历史、编辑信息、关联收支等）。

#### 收支明细区域 (Income & Expenses)

展示：本月收支对比图和周期性收支列表。

##### 交互

图表切换：点击图表可以切换“本月”和“年度”视图。
列表点击：点击某条收支（如“工资”），弹出底部菜单进行编辑（修改金额、周期、日期）或删除。
新增按钮：点击底部的“+”按钮，弹出一个表单，手动添加新的固定或一次性收支项。##

## 完整交互流程图 (User Flow Wireframes)

### 场景一：资产卡片的查看与编辑 (以“负债-房贷”为例)

路径：主页 -> 点击负债 Tab -> 点击房贷卡片 -> 资产详情页 -> 点击编辑 -> 编辑表单

```text
[主页面 - 财富]
      |
(点击 Tab "负债")
      |
      V
+---------------------------+      (点击卡片)      +---------------------------+
| [Tab: 负债]               | -----------------> | [页面: 资产详情]          |
|                           |                     | <返回                      |
| 🏠 招商银行·住房按揭       |                     | 🏠 招商银行·住房按揭       |
| 待还: ¥1.8M  利率: 4.2%   |                     |                           |
| [||||||····] 已还 35%     |                     | 当前余额: ¥ 1,800,000     |
+---------------------------+                     | 初始贷款: ¥ 2,800,000     |
                                                  | 年化利率: 4.2%            |
                                                  | 剩余期限: 240 个月        |
                                                  |                           |
                                                  | 关联收支:                 |
                                                  | - 房贷月供 (¥12,500/月) > | <- 点击跳转收支编辑
                                                  +---------------------------+
                                                  | [编辑资产] [更新余额]      | <- 底部操作栏
                                                  +---------------------------+
                                                                | (点击"编辑")
                                                                V
                                                  +---------------------------+
                                                  | [页面/弹窗: 编辑负债]      |
                                                  |                           |
                                                  | 贷款名称: [招行房贷]       |
                                                  | 当前余额: [1800000]        |
                                                  | 年化利率(%): [4.2]         |
                                                  | 剩余月份: [240]            |
                                                  |                           |
                                                  | [ 保存 ]                  |
                                                  +---------------------------+
```

交互要点：
详情页：展示该资产更详细的静态信息（如初始贷款、年限）。
关联跳转：如果该资产关联了收支（如房贷关联了月供），可以直接点击跳转到收支编辑页。
编辑入口：提供明确的“编辑”按钮修改基本信息，以及“更新余额”按钮（可能触发 AI 对话或手动输入新余额）。

### 场景二：收支信息的管理 (编辑现有项 & 新增项)

路径 A (编辑)：主页 -> 收支区域 -> 点击某条收支 -> 底部弹窗编辑 路径 B (新增)：主页 -> 收支区域 -> 点击“+ 新增”按钮 -> 底部弹窗新增

```text
[主页面 - 财富]
      |
(滑动到收支区域)
      |
+-----------------------------------------------+
| 收支概览                                      |
| [ 图表 ]                                      |
| 月度固定收支:                                 |
| 💰 工资收入  +¥ 30k/月 (15日)                 | <- 点击此条目 (路径 A)
| 🏠 房贷月供  -¥ 12.5k/月 (10日)               |
| ...                                           |
| [ + 新增收支项 ]                              | <- 点击此按钮 (路径 B)
+-----------------------------------------------+
      | (路径 A & B 唤起同一个组件，状态不同)
      V
+=======================================================+
| [底部弹窗 (Modal Bottom Sheet): 编辑/新增收支]           |
+=======================================================+
|                                                       |
| 类型:  (o) 收入   ( ) 支出                             | <- Segmented Control
|                                                       |
| 名称:  [ 工资收入 ]                                   |
| 金额:  ¥ [ 30000 ]                                    |
|                                                       |
| 周期性:                                               |
| [ ] 仅一次                                            |
| [x] 按周期 -> 频率: [每月 v]  日期: [15日 v]           | <- Dropdown & Picker
|                                                       |
| 关联资产 (可选):                                      |
| [ 无关联 v ] (点击可选择 "招行房贷" 等)                  |
|                                                       |
| +---------------------------------------------------+ |
| | [ 删除该项 (仅编辑时显示) ]   [ 保存确认 ]           | |
| +---------------------------------------------------+ |
+=======================================================+
```

交互要点：
底部弹窗 (Modal Bottom Sheet)：使用半屏弹窗，不打断当前页面上下文，体验更轻量。

表单联动：
选择“收入/支出”会改变金额的颜色（绿/红）。
勾选“按周期”才显示频率和日期的选择器。
关联资产：提供一个下拉菜单，列出当前已有的资产，方便用户建立关联（建立连接后，AI 就能更智能地分析）。

## 5类核心资产的交互线框图

### 🏠 房产类 (Real Estate) - 重在“估值与趋势”

房产是高净值、低频交易资产，交互核心是 AI 估值 和 资产属性。
