## 📱 完整测试流程

### 1. 访问应用
打开浏览器访问: http://localhost:8080

### 2. 测试匿名登录
1. 点击 **"匿名体验"** 按钮
2. 应该跳转到聊天页面
3. 点击底部导航的 **"个人中心"**
4. 应该显示:
   - 用户名: "匿名用户"
   - 状态: "点击绑定手机号"

### 3. 测试手机号登录
1. 返回登录页面 (点击退出登录)
2. 输入手机号: `13555555555`
3. 点击 **"发送验证码"** 按钮
4. 查看后端控制台输出的6位验证码
5. 输入验证码，点击 **"登录"**
6. 应该跳转到聊天页面
7. 访问个人中心，应该显示真实手机号

### 4. 测试绑定手机号功能
1. 使用匿名登录进入应用
2. 访问个人中心
3. 点击编辑按钮 (铅笔图标)
4. 在弹出的对话框中:
   - 输入手机号
   - 点击"发送验证码"
   - 查看后端控制台的验证码
   - 输入验证码，点击"绑定"
5. 绑定成功后，个人中心应该显示真实手机号

## 🚨 如果遇到问题

### 前端编译错误
- 检查导入路径是否正确
- 运行 `flutter clean && flutter pub get`
- 重新运行 `dart run build_runner build`

### API请求失败
- 确认后端服务运行在 http://localhost:8000
- 检查浏览器Network面板的错误信息
- 查看后端控制台的错误日志

### 验证码问题
- 确认后端控制台有验证码输出
- 检查验证码是否在5分钟有效期内
- 确认没有超过3次尝试限制
