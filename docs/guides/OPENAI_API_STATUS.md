## 性能影响

### 关键词搜索模式

**优点**:
- ✅ 更快的响应时间（5-20ms vs 10-50ms）
- ✅ 无 API 调用延迟
- ✅ 无成本

**缺点**:
- ❌ 无法理解同义词（"购房" vs "买房"）
- ❌ 无法理解上下文（"投资风险" vs "风险管理"）
- ❌ 精确匹配要求更高

### 实际影响评估

对于 AssetFlow 的使用场景：

- **影响程度**: 中等
- **原因**: 财务术语相对标准化，关键词匹配可以覆盖大部分场景
- **建议**: 开发测试阶段可以使用关键词模式，生产环境建议启用语义搜索
