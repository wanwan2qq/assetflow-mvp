## 核心问题

⚠️ **AI 过度调用 property_search 的原因**：

1. **System Prompt 指令过于强制**
   - 要求"所有房产估值必须通过property_search工具获取"
   - AI 误以为"只要涉及房产就必须调用工具"

2. **缺少上下文相关性判断**
   - AI 没有被告知"只有用户问题与房产估值相关时才调用"
   - 导致用户问 AI 股票时，AI 也会先确认房产估值

3. **Fact Sheet 的"系统推测"标记**
   - 未确认的房产显示"(系统推测)"
   - AI 看到后认为数据不可靠，需要重新确认

## 解决方案

### 立即修复（推荐）

修改 `backend/app/services/chat_agent.py` 的 System Prompt（第179-200行）：

```python
**交互策略 (Interaction Strategy)：**
1. **房产估值**：
   ⚠️ **重要**：只有在以下情况下才需要确认房产估值：
   - 用户**主动询问**房产价值、估值、市场价格
   - 用户**首次提到**新的房产信息（新地址、新面积）
   - 用户**明确要求**进行资产配置分析，且房产信息缺失或不完整
   
   ❌ **禁止**在以下情况下确认房产估值：
   - 用户询问其他投资建议（股票、基金、保险等）
   - 用户只是提到"我有房产"但没有询问估值
   - Fact Sheet 中已有房产信息且标记为"(用户已确认)"

**安全原则：**
- ⚠️ **新增**：只有在用户问题与房产估值直接相关时，才调用 property_search 工具
```

## 启用 Tavily API（可选）

如果需要真实的房产估值数据：

### 步骤 1：获取 API Key
1. 访问 https://tavily.com 注册账号
2. 获取 API Key（格式：`tvly-xxxxxx`）

### 步骤 2：配置
编辑 `backend/.env`：
```properties
TAVILY_API_KEY=tvly-your-real-api-key-here
USE_MOCK_SEARCH=false
```

### 步骤 3：安装依赖
```bash
pip install tavily-python
```

### 步骤 4：重启服务
```bash
python -m uvicorn app.main:app --reload
```

### 步骤 5：验证
```bash
python backend/scripts/test_tavily_search.py
```
