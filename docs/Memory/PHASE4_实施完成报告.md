## 核心功能

### 1. 自动记忆提取

InsightService 自动检测并存储关键生活事件：

| 类别 | 关键词 | 示例记忆 |
|------|--------|----------|
| 健康问题 | 生病, 住院, 手术 | "用户提到家人健康问题，可能需要流动性资金" |
| 重大购买 | 买房, 购房, 换房 | "用户计划购买房产，需要大额资金准备" |
| 退休规划 | 退休, 养老 | "用户关注退休规划，需要长期稳健投资策略" |
| 教育规划 | 孩子, 教育, 学费 | "用户关注子女教育，需要预留教育资金" |
| 负债约束 | 房贷, 负债, 还款 | "用户有房贷压力，需要保守的投资策略" |

### 2. RAG 上下文注入

ChatAgent 自动检索相关记忆：

```
🧠 【RELEVANT MEMORIES】
1. 用户提到母亲生病住院，需要准备医疗费用 (相关度: 0.89)
2. 用户有房贷压力，每月还款2万 (相关度: 0.82)
3. 用户计划2年后购买学区房 (相关度: 0.76)
[重要提示: 这些是用户之前提到的关键信息，请在回复中考虑这些背景。]
```

### 3. 优雅降级

- **无 OpenAI Key**: 降级到关键词搜索
- **无 pgvector**: 仅存储文本，不生成向量
- **嵌入失败**: 存储记忆但不含向量，记录警告
- **搜索失败**: 返回空列表，记录错误

## 使用示例

### 添加记忆

```python
from app.services.memory_service import get_memory_service

memory_service = get_memory_service()

memory = await memory_service.add_memory(
    user_id=1,
    text="用户提到母亲生病住院，需要准备20万医疗费用",
    metadata={
        "category": "health_concern",
        "tags": ["family", "health", "liquidity"]
    }
)
```

### 检索相关记忆

```python
memories = await memory_service.retrieve_relevant(
    user_id=1,
    query_text="用户家人健康情况如何？",
    limit=3,
    similarity_threshold=0.7
)
```
